# Smart AI Assistant (Ollama)

WordPress-плагин: локальный ИИ-ассистент для сайта на базе Ollama и модели `gemma2:2b`. Работает без внешних API, данные не покидают ваш сервер.

## Возможности

- Чат-ассистент на страницах сайта
- Фильтр off-topic: ассистент отвечает только по теме сайта
- Хранение истории диалога в cookie (до 10 сообщений)
- Проверка завершённости ответа с повторным запросом на корректировку
- Автоматический подбор услуг по ключевым словам с выводом ссылки, цены и картинки
- Fallback-поиск по услугам, если модель недоступна

## Стек

- PHP 8+
- WordPress
- Ollama
- gemma2:2b
- ACF (опционально)

## Требования

- WordPress 5.8+
- PHP 8.0+
- Ollama, установленная локально или на отдельном сервере
- Модель `gemma2:2b`
- Плагин ACF (опционально, для полей `service_price` и `main_image`)

## Установка Ollama

```bash
curl https://ollama.ai/install.sh | sh
ollama pull gemma2:2b
